# Theme Visual Assets

This package contains the production assets for the four Casa Viva themes.

## File contract

- `appBackground.svg`: full-page app background.
- `authBackground.svg`: authentication surface background.
- `onboardingHero.svg`: onboarding hero illustration.
- `homeHero.svg`: home hero illustration.
- `themePreview.webp`: theme selector preview thumbnail.
- `footerDecoration.svg`: footer ornament.
- `headerDecoration.svg`: header ornament.
- `modalDecoration.svg`: modal ornament.
- `subtlePattern.svg`: low-interference repeating pattern.
- `expensesEmpty.svg`, `absencesEmpty.svg`, `tasksEmpty.svg`, `houseEmpty.svg`, `rulesEmpty.svg`: empty states.
- `homeIcon.svg`: themed home icon.

## Notes

- All assets are self-authored.
- No photographs are used as permanent app backgrounds.
- SVG assets are vector and scalable.
- `themePreview.webp` is rasterized for denser presentation in the theme picker.
- The previews are designed for low interference, preserving legibility on top of complex backgrounds.

## Generated boards

Each theme folder contains a `preview-board.html` file showing the full asset set for that theme.
