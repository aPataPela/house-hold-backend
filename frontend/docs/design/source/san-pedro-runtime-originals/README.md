# San Pedro runtime source exports

These files are the original raster exports supplied by
`casa_viva_all_theme_packs`. They are documentation-only because the preview
and empty-state crops include embedded labels or neighboring board content.

The normalized WebP files in `public/assets/themes/san-pedro/` retain only the
approved illustration area. They must remain text-free at runtime. The tasks
and house crops use the corresponding regions of the approved San Pedro board
because the individual source exports clipped their artwork.
